# Moon Bloom

夜桜モチーフのスキンケアブランド「Moon Bloom」の、**ランディングページ（LP）**です。
ポートフォリオとして作った、**架空のブランド・商品のサイト**です（実在の商品ではありません）。

- 公開ページ：https://misaki36.github.io/moon-bloom/
- 制作：桑本 美咲（Kuwamoto Misaki）

> ⚠️ 商品・価格・お申し込みフォームは、すべて練習用です。フォームを送信しても、どこにも送られません。

---

## どんなページ？

忙しい夜でも、これ1本でケアできる「オールインワンスプレー」と、スプレーの前に使う「導入美容液」を紹介するLPです。
ゴールは「**7日間お試し（¥980）**」への申し込みです。

| セクション | 内容 |
|---|---|
| FV（最初の画面） | 夜桜と月の背景、シャボン玉に入った商品、「7日間お試しはこちら」ボタン |
| 商品紹介① | オールインワンスプレーの特長と、成分 |
| 商品紹介② | 導入美容液の説明と、成分 |
| 7日間お試し | お試しセットの中身（スプレー30ml＋導入美容液10ml）、価格、申し込みフォーム |
| よくある質問 | 質問を押すと、答えが開く |
| お問い合わせ | フッターのボタンから、フォームが開く |

## 使った技術

- HTML（意味のあるタグ：`header` `nav` `main` `section` `footer` など）
- CSS（Flexbox、Grid、`@media` でスマホ・PC対応、CSS変数）
- JavaScript（フォームとよくある質問の開閉）
- Google Fonts（Shippori Mincho、Cormorant Garamond）
- GitHub Pages で公開

## 工夫したところ

- **ひと目で商品が分かるFV**：シャボン玉の中に商品を入れ、最初の画面で何の商品か伝わるようにしました
- **スマホ・PCの両方で見やすく**：画面の幅に合わせて、並び方や飾りの大きさを調整しました
- **アクセシビリティ**：画像に代わりの文章（alt）をつける、キーボード（Tabキー）で操作したときに枠線を出す、など
- **フォームの安全面**：`method="post"`、入力チェック（`required`）、`autocomplete` を設定。本番では、HTTPSの送信先、XSS・SQLインジェクション・CSRFの対策が必要なことをコメントに残しています

## 表示速度の改善

PageSpeed Insights（スマホ）で測りながら、1つずつ改善しました。

| 項目 | 改善前 | 改善後 |
|---|---|---|
| 点数 | 59 | 63 |
| FCP（最初に何か見えるまで） | 6.8秒 | 5.1秒 |
| LCP（一番大きいものが見えるまで） | 10.2秒 | 7.9秒 |

PCは87点、ユーザー補助・おすすめの方法・SEOは100点です。

やったこと：

- 画像をすべて **WebP** に変換（合計 約31MB → 約0.9MB）
- 画面の大きさに合った画像を選ぶ（`srcset` / `sizes`）
- Google Fonts を、画面の表示をじゃましない方法で読み込む（`preload`）
- 日本語フォントの太さを減らす
- 最初の画面の背景画像を、先に読み込む（`preload`）
- 大きい飾り画像（霧など）の画質を調整して軽くする

直せなかったこと：

- 「効率的なキャッシュ保存期間」は、GitHub Pages では設定できないため、そのままにしています

> 数字は、遅い回線・遅いスマホを想定した **シミュレーション** です。測るたびに少し変わります。

## 自分のパソコンで動かす

1. このリポジトリをダウンロード（または `git clone`）する
2. VSCode で、フォルダを開く
